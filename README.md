# 📚 Manga Batch Downloader

A lightweight web-based tool that lets manga readers open multiple manga episode pages in sequence with a single click. This is designed for users who want a smoother reading experience without navigating manually through each chapter.

> **⚠️ Important:** This tool does **not** download or scrape image files. It only opens publicly available URLs in your browser.

---

## 🚀 Features

- Easy-to-use interface with Bootstrap styling
- Opens multiple chapter links automatically in new tabs
- Built-in input validation to ensure proper use
- Helps readers avoid intrusive ads or distractions by batching link openings

---

## 📌 How to Use

1. Copy and paste the base URL of the manga (e.g., `https://images.mangafreak.net/downloads/One_Piece_`).
2. Specify the **start** and **end** episode numbers you want to open.
3. Click **Continue**.
4. Your browser will open each episode URL in a new tab every second.

> **Note:** On your first attempt, your browser (especially Chrome) might show a message in the address bar asking whether to allow multiple downloads or tab openings. Please select **"Allow"** to enable it to function properly.

---

## ⚖️ Disclaimer & Ethical Note

This tool is intended to assist readers in navigating manga websites **they already access freely**. It does **not** bypass authentication, does not scrape images, and does not harm the host servers.
